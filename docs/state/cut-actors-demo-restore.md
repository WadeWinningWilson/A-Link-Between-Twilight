## THE COVENANT GATE — READ BEFORE FILING A BREACH (№119, standing)

Chats keep re-opening this and re-reporting the same false positives. The gate
has a **narrow, specific** meaning. Grep hits are not breaches.

**What the covenant actually protects:** the shipped binary and the vanilla game
tree must contain no *Wind Waker content* — no WW arcs, no WW bytes, no WW
dialogue, and no player-visible string naming a WW place or character. All WW
content lives in the mod folder. (R6: player-visible strings describing WW
content come from DATA, never from source.)

**Three classes that are NOT breaches. Do not file these:**

1. **Comments.** `// Outset's authored span is ~100k units` never reaches the
   binary. The compiler strips it. Source comments are exempt, full stop — a
   grep over source without stripping comments will drown you in these.
2. **Nouns TP and WW share.** `Magic Armor`, `Bow`, `Bomb`, `Boomerang`,
   `Iron Boots`, `Hookshot`, `Bottle`, `Telescope`, `Grappling Hook` are all
   real TP items. `Link's House` is a real TP location (Ordon, `R_SP01`).
   `"magic armor bought malo mart"` is a TP event flag. A term list that flags
   these is a broken term list, not a finding.
3. **WW-origin data that TP ITSELF SHIPS.** TP's own `itemmdl` archive is
   **21/21 byte-identical** to WW's (see `docs/TPHistory.md`). Those models are
   vanilla TP assets. Naming them in a debug/editor viewer names *TP's* data,
   not imported WW content. The editor's item dropdown is in this class.

**What IS a breach:** a WW place or character name in a string literal that
ships — a warp-menu label, a dialogue line, an on-screen caption, a resource
path pointing outside the mod folder. Player-facing, and describing content
TP does not ship.

**Before filing, do all three:** (a) strip comments; (b) check the term against
TP's own content; (c) check whether TP already ships the asset. If it survives
all three, file it with file:line and the literal quoted.

**Settled, do not re-report:** `L-1` (`RegionEntry("Outset Interiors")` in
`map_loader_definitions.h`) and `L-2` (`"Link's House (interior)" -> R_DL01`)
were **already removed**; that block now holds the №99 R1/R2 comment stating the
rule. Verified 2026-07-20 — a gate over tracked source string literals returns
**zero** genuine hits. Reports of L-1/L-2 are reading a stale copy of the file.
